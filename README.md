# fetchframe

Fetch filesystem frame paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/fetchframe/

## Install / run

```bash
git clone https://github.com/theworker02/fetchframe.git
cd fetchframe
node src/cli.js
node --test
```
